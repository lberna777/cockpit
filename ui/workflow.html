Descrizioni e argomenti sono letti dal frontmatter dei comandi veri, in Vault/UniCode/.claude/commands/: questa pagina non può divergere da ciò che lanci.

Il flusso di una sessione

  1. /sessione <CODICE> opzionale — vuoto = corso attivo dal briefing

    Avvia la sessione di studio o cambia il corso in focus. Uso: /sessione [CODICE]

  2. /lezione <CODICE> <ID modulo> — es. FI2 3A, SO 2B, CA 4

    Crea la lezione strutturata per un modulo dai materiali del corso. Uso: /lezione <CODICE> <ID> (es. /lezione FI2 3A)

  3. /lab <CODICE> <ID modulo> — es. LAS 3D, FI2 2A

    Genera la guida-lab operativa per un modulo dalle fonti del corso (passo 3 del flusso). Uso: /lab <CODICE> <ID>

  4. /appunti <CODICE> <ID modulo> — es. FI2 3A, SO 2B

    Elabora gli appunti grezzi di un modulo in appunti definitivi e aggiorna lo stato. Uso: /appunti <CODICE> <ID>

  5. /verifica <CODICE> <ID modulo> — es. FI2 3A

    Verifica qualità di una lezione o di appunti generati: confronta con la fonte e segnala i gap. Uso: /verifica <CODICE> <ID>

  6. /ripassa <CODICE> <ID modulo> — es. FI2 3A, LAS 2B

    Sessione di ripasso adattivo su un modulo completato. Genera domande nuove, non quelle dell'autoverifica. Uso: /ripassa <CODICE> <ID>

  7. /simula <CODICE> corso — es. FI2, SO, CA

    Simulazione d'esame: usa una prova passata se esiste, altrimenti genera domande cross-modulo. Uso: /simula <CODICE>

  8. /chiudi

    Chiude la sessione di studio: raccoglie il giudizio, aggiorna stato e log. Facoltativo — la traccia meccanica è già automatica.

Strumenti trasversali

  • /lacune Analisi gap: moduli a rischio, ripasso scaduto, errori ricorrenti, e un piano d'azione prioritizzato.
  • /pdf-batch <CODICE> opzionale — vuoto = tutti i corsi aperti Converte in PDF le lezioni e gli appunti markdown che non hanno ancora un PDF. Poi git add + commit + push.
  • /piano Genera il piano di studio per oggi basandosi su briefing, tracker e sessione d'esame in corso.
  • /stato Riepilogo rapido: stato dei moduli del corso attivo, avanzamento e prossimo passo.

Skill

  • studia checkpoint mentre annoti una lezione o una guida-lab inline.
  • unicode-output-gate verifica gli standard di qualità prima di considerare finito un output di studio.
  • unicode-session-close chiusura di sessione: nessun file di stato lasciato indietro.
  • unicode-link-note tiene connesso il grafo dei wikilink quando nasce o si sposta una nota.
