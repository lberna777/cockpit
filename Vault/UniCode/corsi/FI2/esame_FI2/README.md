# Kit d'esame FI2

Cosa portare alla prova pratica (materiale consultabile: verificare le regole esatte dell'appello).
Si cerca in quest'ordine:

1. **`../appunti/prontuario_FI2.md`** (e il PDF in `../pdf/appunti/`): il punto d'ingresso.
   Errori per testo del messaggio, *Indice per bisogno* → sezione + file svolto.
2. **`svolti/`**: i progetti Eclipse dei LAB e delle prove **svolti da Lorenzo**, con i test verdi.
   Accanto al codice, `confronto_<ID>.md`: differenze con la soluzione del docente e quale forma
   seguire (sempre la sua).
   Una cartella per voce, nome = ID (`LAB02_Frazione`, `prova_2025-02-12_TimeSheet`, …).
3. **Fonti ufficiali**, ultima risorsa: soluzioni delle prove in `../prove/`, slide in
   `../materiali/slide/`.

Il kit si assembla su una chiavetta a ridosso dell'esame; fino ad allora cresce qui.
